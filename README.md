# Shorts Maker Pro

Upload a video file, get short segments, and download vertical 9:16 shorts directly in your browser.

## Modes

1. Upload video only → auto split into equal shorts → Trim & Download
2. Upload video + paste transcript → smart theme-based selection → Trim & Download
3. YouTube link (optional) → transcript analysis

## Run locally

npm install
npm start
Open http://localhost:3000

## Notes

- Video trimming runs 100% in your browser using FFmpeg (ffmpeg.wasm)
- No YouTube downloading (against YouTube ToS)
- Use only your own videos or videos you have rights to
